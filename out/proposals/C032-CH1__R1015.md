# Unsupervised Anomaly Detection for OT Networks Deployable on Edge Hardware

**Company:** SecureEdge Labs [C032], Cybersecurity, 19 employees, NTP Novi Sad.  
**Faculty:** Faculty of Technical Sciences, Department of Computing and Control Engineering [R1015].  
**Format:** Joint project  
**Supervisors / contacts:** Principal investigator / Associate Professor (academic) and Designated technical project lead (senior security engineer) — escalation point at each milestone (company)

### The problem
- Detecting attacks on Modbus and BACnet networks is impractical with rule-based or statistical methods alone because real incidents are rare and baselines drift with production changes. [C032-CH1]
- No labelled attack data is available because customers do not permit attack simulations on live plant and public OT datasets do not match field conditions. [C032-CH1]
- Any detection model must run inference on an edge sensor with tight hardware constraints, limiting the complexity of approaches that can be deployed. [C032-CH1]

### Work packages
1. Can autoencoder-based models trained solely on benign Modbus and BACnet traffic generalise across three sites with differing operational profiles?
2. What model architectures and quantisation strategies allow anomaly detection inference to run within the memory and compute limits of an ARM-based edge sensor?
3. How should traffic window size and encoding granularity be tuned to minimise false positives during shift-change and seasonal production transitions?
4. Can a federated update mechanism allow site-level models to share knowledge without transmitting raw packet data?
