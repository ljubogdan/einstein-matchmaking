# Fewer wrong bans, faster moderator decisions

**Company:** VoxelRealm a.d. [C115], Game development, 120 employees, Novi Sad.  
**Researcher:** Dragana Tadić, Assistant Professor, Faculty of Technical Sciences, Department of Computing and Control Engineering [R0856].  
**Format:** Contract research  
**Supervisors / contacts:** Principal Investigator (academic) and Lead Game Engineer (integration owner, single point of contact) (company)  

### The problem
- The anti-cheat system flags about 900 accounts a day but the manual review team can only process 200, leaving the rest automatically banned or waiting in a queue for days. [C115-CH1]
- Daily active users dropped 7% in the last quarter, with players citing false bans as a reason for leaving on forums and Discord servers. [C115-CH1]
- Lowering false-positive thresholds in BehaviorWatch consistently causes more genuine cheaters to be missed, and the studio lacks the specialists to build a better automatic decision model. [C115-CH1]

### Work packages
1. Can a semi-supervised anomaly detection model trained on 18 months of BehaviorWatch event logs achieve a lower false-positive rate than the current threshold-based system, measured against consensus labels produced by senior moderators on 2,000 randomly sampled flagged accounts?
2. Does adding a sequence modelling layer over player action event logs improve detection of coordinated economy abuse compared to the single-session feature baseline, measured against confirmed ban records in the dataset?
3. Can an explainability layer attached to the model reduce average moderator decision time per case, measured in seconds against a pre-integration baseline timed across 200 live review sessions on the current workflow?
4. Does an adaptive retraining protocol maintain model precision across patch updates in the six-month dataset window, measured against drift points identified from patch release dates?

### Plan
